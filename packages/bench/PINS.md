## Notes per pin

- **GateMem.** Open-label: `query_type`, `expected_action`, `judge_spec` and `leak_targets` sit in the files the agent reads, so the bench adapter strips them before anything reaches the plane. The literature-review note (`docs/readings/litreview/2606.18829-gatemem.md`) says no code was found; the repository above supersedes it.
- **MPBench.** Not released. The request in `docs/research/mpbench-request.md` is to be sent by the lead (plan decision 6, 2026-10-29); its sent date goes in the row above when it is sent, and is pending. The poisoning arm's choice was dated on 2026-10-29: MEM-INV-Bench, since MPBench has no release (ADR 0029); if MPBench is released before card X3 starts, the lead may add it by a decision entry and a pin PR.
- **MEM-INV-Bench.** Checked on 2026-10-29 the way S0.6 checked the others (`gh api repos/yedidel/mem-inv-bench`, its tree and `README.md`, `REPRODUCE.md`, `release.json`, `CITATION.cff`, `THIRD_PARTY_NOTICES.md` at `cf3c9a4`; the Hugging Face API for the dataset; the paper, arXiv 2606.24322, HTTP 200). Code and data are released, which the literature-review note had not checked. It is not MPBench's design: it measures whether poisoned memory drives a consequential action (pay, wire, purchase, setting change, data send) past an authorization monitor, across laundering channels, not whether a poisoned write is stored and later retrieved. The released records are recorded evidence of the authors' runs (4,384 records, five plans) and replay offline; scoring a new condition, such as Engram's plane, would mean running the runners in `code/` live, which REPRODUCE.md says needs provider setup and budgets (not tried; how a defence plugs in was not read in detail). The one open item at the check is pull request #1, adding an optional contextual and temporal authority extension benchmark.
- **LongMemEval.** Results on the cleaned files are not comparable with the original 2024 files.
- **MERIT.** Single-group and unreviewed; its `HYPOTHESES.md` refers to a `prereg-v1` tag that does not exist.
- **tau2-bench.** Pinned to the `v1.0.1` release rather than the moving head (`96a3ef9`, 2026-10-15): the repository is now tau3-bench and its numbers are not comparable with the 2025 paper. It does not test memory; it is the tool-use harness a memory layer is inserted into.
