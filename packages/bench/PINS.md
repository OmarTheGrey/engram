# Benchmark pins

Each benchmark is pinned to one upstream commit and one data revision. A pin never moves mid-experiment (AGENTS.md rule 8); moving one is its own PR with the change in results explained and a `change` log entry. Facts below were checked on 2026-10-17 with `gh api`, the Hugging Face API and the papers; every URL was rechecked on 2026-10-22 and returned HTTP 200.

## Notes per pin

- **GateMem.** Open-label: `query_type`, `expected_action`, `judge_spec` and `leak_targets` sit in the files the agent reads, so the bench adapter strips them before anything reaches the plane. The literature-review note (`docs/readings/litreview/2606.18829-gatemem.md`) says no code was found; the repository above supersedes it.
- **MPBench.** Not released. Until it is, the poisoning arm uses the fallback card; MEM-INV-Bench (2606.24322) is the alternative named in `docs/readings/litreview/sota-2026.md`.
- **LongMemEval.** Results on the cleaned files are not comparable with the original 2024 files.
- **MERIT.** Single-group and unreviewed; its `HYPOTHESES.md` refers to a `prereg-v1` tag that does not exist.
- **tau2-bench.** Pinned to the `v1.0.1` release rather than the moving head (`96a3ef9`, 2026-10-15): the repository is now tau3-bench and its numbers are not comparable with the 2025 paper. It does not test memory; it is the tool-use harness a memory layer is inserted into.
