**What.** Step-0 task S0.8 added the `Db` interface (exec, prepare, transaction with savepoints) over `node:sqlite`, a forward-only migration runner, the append-only event log (`appendEvent` with a dense seq, queries by item, actor and scope) and an item projection with `rebuild()`.

**Why.** ADR 0003: the event log is the source of truth and store state is a projection that must be rebuildable.

**Result.** 9 unit tests and a fast-check property over 500 random event sequences (seeded from the test name): the rebuilt projection equals the incremental one. Replaying events in reverse breaks it after 6 runs with a shrunk two-write counterexample and the seed printed, so the test can fail.

**Consequence.** Core never reads the clock; callers supply event ids and timestamps. Node prints an ExperimentalWarning for `node:sqlite`.
