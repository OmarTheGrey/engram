**What.** The first `make test` after committing the fixture-size fault set failed in the CLI's doctor tests: the benchmark-pins check reported `fixtures/bench/longmemeval-faults has no manifest.json`.

**Why.** `engram doctor` treats every directory under `fixtures/bench/` as a vendored benchmark fixture that must carry a manifest and match a pin in PINS.md. The fault set is generated by the repository, not vendored, so it has neither.

**Result.** The set moved to `fixtures/fault-sets/longmemeval/`, with every reference (the Makefile, the tests, AGENTS.md and CLAUDE.md, the README, the card); the doctor tests pass. The same run's 30-second timeouts in the Letta and CLI tests came from load: sixteen generator processes ran beside it.

**Consequence.** Generated sets live outside `fixtures/bench/`; vendored data stays there.
