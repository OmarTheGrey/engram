**What.** Each proposed value of the draft is logged as a `decision` entry whose What begins "Proposed for the lead", not as a `finding`.

**Why.** The review (finding F12) noted that these entries record values not yet decided. The convention defines a decision as a choice another person could have made differently, which the drafter's choice of what to propose is; a `finding` is something learned, which a proposal is not, and the convention has no proposal type.

**Result.** 23 entries, one per proposed value or seed choice, keep type `decision`, each saying it is a proposal and that the lead's answer entry supersedes it (convention rule 5).

**Consequence.** The thesis's decisions draft lists them as the drafter's proposals until the lead's answer entries supersede them.
