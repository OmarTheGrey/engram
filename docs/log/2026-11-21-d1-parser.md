**What.** Card D1 adds a pure parser in `packages/core/src/distill/episode.ts` from pi session JSONL (version 3) to an episode: the final branch's steps, each tool call joined to its result, the outcome, and every abandoned branch with the entry it was left at, its leaf and pi's branch summary.

**Why.** Distill learns from past sessions (ADR 0001 point 5, ADR 0012), and later Distill cards need one episode shape. Core does no I/O, so the parser takes text.

**Result.** 17 unit tests pass. Step kinds follow the OpenAI Agents SDK span vocabulary (MIT, idea only): `generation`, `function`, `custom`, plus pi's `user` and `summary`. The format is read from pi 1.3.0's `docs/session-format.md` and `dist/core/session-manager.js`, cited in the file.

**Consequence.** Card D2 reads `Episode` items. Nothing in a registered condition calls the parser.
