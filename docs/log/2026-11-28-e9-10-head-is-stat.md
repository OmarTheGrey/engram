**What.** The classifier's `head` argument is the file's stat head, `{ size, mtime }`, not a prefix of its content.

**Why.** The research design (18a) named a bounded content head; the card and the orchestrator say never content (rule 12). Classifying by path alone loses nothing for the eleven rows, all of which are named by path in the vendors' documentation.

**Result.** `packages/cli/src/discover.ts` lists folders and stats matches; a test fails if either discover source calls a read of file content (`packages/cli/test/doctor-discover.test.ts`).

**Consequence.** If wrong: a location only a file's front matter identifies cannot be classified. Cost: one more argument later, by a card that justifies reading content.
