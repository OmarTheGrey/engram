**What.** `make test-repro` is no longer a stub: it reruns every row of `research/results/MANIFEST.md` and fails on a sha256 that differs.

**Why.** Plan decision 10 of `docs/tasks/prereg-v1-plan.md`, with the first research scripts.

**Result.** `research/scripts/reproduce.py` runs each row's script as `python <script> --config <config> --out <temporary file>` from the repository root, compares the regenerated bytes and the committed file with the row's sha256, checks every row before deciding, and exits 1 on any difference. Tests on a toy manifest cover a match, a regenerated difference and a committed file that drifted. The AGENTS.md and CLAUDE.md command line changed identically. A script needing pinned upstream data fetches it into `.engram/upstream` (data only), so a fresh clone needs the network; CI does not run it.

**Consequence.** Every result of this PR and later ones is held to its hash.
