**What.** ADR 0013 gains a proposed amendment of card A5: Mem0 version 3 as its migration guide and the installed `mem0ai` 3.3.1 show it, and the capability-honesty cases.

**Why.** ADR 0013's Context still described Mem0 version 2 (ADD, UPDATE, DELETE, NOOP extraction and a graph variant).

**Result.** The guide (read 2026-11-21) says graph memory is removed from the open-source package and extraction is ADD-only. In `mem0ai` 3.3.1, `MemoryConfig` has no graph field, `add` returns ADD only, and UPDATE and DELETE history rows come only from the explicit `update` and `delete` methods. Version 3 also filters expired memories at read on the wall clock unless `showExpired` is set; the adapter never sets an expiration date. No code changes.

**Consequence.** The amendment joins the lead's list as proposed.
