**What.** The review of PR #33 confirmed two defects in `offboard` and one gap in its tests, and fixed them test first.

**Why.** A handover store failure threw without an event (AGENTS.md rule 3). Erasure deleted every ref an erased item held, even one an item outside the person scope also holds, deleting that item's bytes. The redaction and the explanation-row removal ran only on SQLite, and no test read before offboarding, so the row removal was never exercised.

**Result.** A failed handover now appends one deny event (`engram/write/store-failure`) and throws before erasing; a shared ref is kept and reported. offboard-edges.test.ts, 5 tests, runs the erasure on SQLite and embedded Postgres and finds the same log; each fix, broken on purpose, fails its test.

**Consequence.** ADRs 0010 and 0021 amended (the decision entry of the same day).
