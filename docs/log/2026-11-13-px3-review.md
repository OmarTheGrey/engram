**What.** Review of PR 39 fixed two findings: the `/engram` template hard-coded lint and simulate as waiting for L1 and E8.9, and the acceptance test was not hermetic.

**Why.** L1 adds lint to core, server and CLI but no pi tool, so a template keyed on the card would promise lint that never arrives; E8.9 gives `memory_simulate` a candidate preset the template never passed. The acceptance test failed on a machine with `~/.agents/skills` (see the failure entry).

**Result.** The template calls `memory_lint` only when the session registers it and passes simulate's candidate; `test/unit/templates.test.ts` checks both and that neither file names a store CLI invocation (2 of 4 failed before the fix). `packages/pi-package`: 13 of 13 pass.

**Consequence.** ADR 0001 amended, `docs/log/2026-11-13-px3-decision-template-detects-tools.md`.
