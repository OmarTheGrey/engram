**What.** ADR 0024 (Db backends: one synchronous contract, SQLite per user by default, Postgres on a worker thread) was drafted as accepted, pending the lead's review, on the lead's instruction to decide the plan's open points.

**Why.** Card E1.1 names a Postgres backend, the `Db` contract is synchronous, and Node has no synchronous Postgres driver; deferring would leave the swap ADR 0003 promised untested, and an asynchronous `Db` would rewrite load-bearing code before Gate B.

**Result.** `docs/decisions/0024-db-backends-synchronous-contract.md`: a backend contract suite, a worker-thread Postgres backend with an advisory lock in the outer transaction, SQLite per user as the default, both backends in CI.

**Consequence.** PR 2 of `docs/tasks/gate-a-e0-e1-e2-plan.md` builds it. The lead accepts, amends or reverses it; until then the plan follows it.
