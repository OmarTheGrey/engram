**What.** ADR 0020 was decided: the code is licensed under the Apache License 2.0, with the text in `LICENSE`.

**Why.** The code needs a licence before the public release planned for roadmap week 23; the lead chose Apache-2.0 over MIT and AGPL-3.0.

**Result.** `LICENSE`, the root `package.json`, the README and the roadmap name Apache-2.0; every ADR in the index now has a status other than proposed.

**Consequence.** Contributions carry Apache-2.0's patent grant; the licence of the thesis text is a separate decision.
