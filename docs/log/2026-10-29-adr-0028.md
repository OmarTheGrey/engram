**What.** ADR 0028 (the Letta adapter works over MemFS on local disk) was drafted as accepted, pending the lead's review, and ADR 0013 amended to point at it.

**Why.** ADR 0013 named Letta's server client, which needs a Letta server and its Postgres, so Docker or a hosted account; card A2 named Letta's git-backed context files, which Letta Code's MemFS is, and a local-only agent's repository needs no server.

**Result.** Items as `engram/<id>.md` with Letta's frontmatter and Engram's fields, an `engram/MEMORY.md` index outside the always-loaded root, one commit per write and delete, lexical search over the adapter's index, history from git, the `git` executable and no new dependency.

**Consequence.** PR 2 of the Gate B plan builds it; Gate B's two-store criteria run on Mem0 and Letta offline.
