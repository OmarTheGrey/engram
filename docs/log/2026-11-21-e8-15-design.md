**What.** Card E8.15 designed `engram tui`, a terminal interface over the `engram` CLI, in `docs/design/tui.md`, with ADR 0044 and the implementation card.

**Why.** The lead asked for a TUI that is friendly and appealing, loses no feature, and makes everything easy to reach.

**Result.** The spec inventories every command, flag, positional, environment variable, exit code and output mode, the four API routes no command calls, and the commands of eleven cards in flight, each mapped to a screen, with a parity table and its test (section 3.8). It has 31 screens with mockups at 80x24 and six wide ones at 120x40, drawn from real CLI output on the fixtures by a script that refuses an over-wide line; keys, the palette, forms with the CLI's own validation, confirmation, undo, states, accessibility and the test layers.

**Consequence.** E8.15a to E8.15e implement it in that order once the lead answers item 62.
