**What.** ADR 0027 (one HTTP contract for every surface) was drafted as accepted, pending the lead's review, on the lead's instruction.

**Why.** Cards E8.1 to E8.6 needed one answer to four questions: where OpenAPI comes from, how the CLI calls a client without a running server, who the caller is without authentication, and what a local browser page can do to a localhost server.

**Result.** A Hono route table is the single source, OpenAPI is built from it with `z.toJSONSchema`, the client is generated; the client runs in process unless a server is named; the server is loopback only with `Host`, `Origin` and content-type checks; the actor is self-asserted per request, the MCP server's fixed at launch with source `model`; the inspector reads through `Plane.read` and `visibleEvents`.

**Consequence.** PRs 3 and 4 of the Gate B plan build it. No compose `server` service until authentication.
