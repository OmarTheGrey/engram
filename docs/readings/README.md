## Note template

```
# <arxiv id or short name>  ·  <title>
Claim        one sentence, in your words
Method       two or three sentences
Numbers      the three figures worth remembering, with the table or section they came from
We borrow    what Engram takes from this paper, and where it lands (field, lint, gate, task card)
We differ    what Engram does that this paper does not, stated so the paper's authors would agree
Risk         the one finding here that could weaken a claim we make
Question     one question for the discussion
(max 250 words)
```
