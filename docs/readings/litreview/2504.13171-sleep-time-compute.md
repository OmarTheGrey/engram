## Claim
Reasoning over a context offline, before the query arrives, cuts test-time compute about 5 times for the same accuracy and amortises across related queries.

## Method
Stateful GSM-Symbolic, Stateful AIME, a multi-query variant, and an agentic software engineering case study. Abstract only.

## Key numbers
- About 5x less test-time compute; up to 13 and 18 percent accuracy gains with more sleep-time compute; 2.5x lower average cost per query on the multi-query set (abstract).

## What Engram borrows
Idle-time scheduling for the consolidation job: a seeded, cached batch under a budget, not on the write path.

## What Engram does differently
The artefact is a candidate item that must pass the write gate, not a cache.

## Risk to our claims
The gains are on reasoning tasks, not memory hygiene, and do not transfer by assumption.

## Open question
Does predictable access (the paper's correlate) identify which scopes are worth consolidating?
