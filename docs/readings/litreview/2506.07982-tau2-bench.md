## Claim
When the simulated user also holds tools and state (dual control), agent success falls by about 20 points relative to a mode where the agent controls everything, and the drop comes from guiding the user rather than from reasoning.

## Method
Three domains: retail (115 tasks), airline (50), telecom (114 subsampled from 2,285 generated, with 15 user write and 15 user read tools) (Table 1). Telecom is a Dec-POMDP with two players who alternate turns, each with its own tools and observations (Sec. 3.1). Tasks are composed from atomic subtasks with initialisation, solution and assertion functions, so each is verifiable by construction (Sec. 3.2). Reward is a product of components named in `reward_basis`, by default a hash of the final database state against a replay of gold actions, times a substring check on required `communicate_info`; natural-language assertions are LLM-judged but off by default (docs/evaluation.md, Sec. 3.3). Agents are function-calling LLMs through LiteLLM at temperature 0; the user simulator is gpt-4.1; four runs per task for pass^k (Sec. 4.1).

## Key numbers
- pass^1, retail / airline / telecom: claude-3.7-sonnet 0.79 / 0.50 / 0.49; gpt-4.1 0.74 / 0.56 / 0.34; o4-mini 0.71 / 0.59 / 0.42; gpt-4.1-mini 0.66 / 0.51 / 0.44 (Figure 3, read from figure text).
- pass^4 telecom: gpt-4.1 0.19, o4-mini 0.26, claude-3.7-sonnet 0.25 (Figure 3).
- Telecom ablation, gpt-4.1: default 0.34, no-user 0.52, oracle plan 0.73; o4-mini 0.42 / 0.67 / 0.96 (Figure 4, Sec. 4.2).
- Default-mode success near zero past 7 actions per task (Figure 5).
- Simulator error rates: telecom 16 percent total, 6 critical; retail 40 and 12; airline 47 and 13 (Table 2).
- Cost per task about $0.086 agent and $0.059 simulator with a gpt-4.1 pair (Sec. 4.1).

## What Engram borrows
tau2-bench is Engram's deterministic action benchmark: the database-hash reward means H1 and H5 here need no judge. The compositional generator with assertion functions is the model for Engram's procedural fixtures in the D-cards: a procedure is admitted (ADR 0011) only if replaying it satisfies the assertions k of n times. pass^k is adopted as the H5 metric, because a procedure that works once and fails thrice is what retirement on drift is for. The `HalfDuplexAgent` interface and factory registration are what the pi runner wraps, with the Engram extension loaded or not by condition. The simulator error audit (two annotators, four criteria) is the template for the label audit in ADR 0015.

## What Engram does differently
tau2-bench has no memory across tasks. Engram runs tasks in arcs so a procedure mined from one telecom task is available to the next; the ungoverned procedural condition stores every induced workflow, the governed one admits only validated ones. Simulator and policy document are fixed across conditions.

## Risk to our claims
With 114 telecom tasks and a 16 percent simulator error rate, a few points between conditions can be simulator noise, and H5 could be swamped. Mitigation: pass^k over four runs, paired bootstrap on the same task list, the ADR 0016 stopping rule, and a reported agreement rate between simulator runs under the same seed.

## Notes
Dataset: 279 tasks across the three paper domains; the repository adds `mock` and `banking_knowledge`. Task type: multi-turn customer-service conversations with tool calls; telecom is dual-control. Judge: deterministic (DB hash and substring checks); an optional LLM-judged `nl_assertions` component is experimental and not in the default `reward_basis`. Plug-in: subclass `HalfDuplexAgent`, implement `get_init_state(message_history)` and `generate_next_message(message, state)`, register via `registry.register_agent_factory` in `src/tau2/registry.py`, run `tau2 run --domain ... --agent <name>`; a Python class inside the repo, not an external process, though any LiteLLM provider works for the model. Licence: MIT. Leaderboard at taubench.com. Version read: v1, June 2025. Limitations (Sec. 5): simulator needs improvement; curated user tools not yet in airline and retail; the expert-novice gap is not modelled.
