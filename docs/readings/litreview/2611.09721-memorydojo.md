## Claim
Every tested memory system carries a single early poisoned tool observation forward into later sessions, but how far the poison reaches differs strongly by memory architecture, and an optimiser aware of the memory raises it further.

## Method
Task templates from AgentDojo (Workspace, Travel, Banking, Slack) are concatenated into multi-session trajectories: 155 in all, in same-domain (93), cross-domain (31) and history-prefixed (LongMemEval-S prefix) collections. One poison prompt is appended to one tool observation in an early session; the objective is a later behaviour (send an email, send money, recommend a hotel). Five memory systems run through per-system adapters on a retrieve, interact, write cycle: A-MEM, Graphiti, Letta, Mem0, Memora. Metrics: behavioural reach (BR, any later session) and task-level behavioural reach (BRT, pooled over post-insertion tasks), plus insertion and retrieval success.

## Key numbers
- Same-domain, unoptimised: BR up to 45.70 percent, BRT up to 21.02 percent, A-MEM highest; Graphiti and Mem0 under 8 percent BRT (Table 1).
- Optimised: A-MEM 70.97 percent BR and 44.01 percent BRT; Letta 46.26 percent BRT; Graphiti lowest at 9.31 percent (Table 1).
- Cross-domain: Letta highest BRT, 14.29 percent; Graphiti 2.73 percent (Table 9).
- Prefixing LongMemEval histories lowers reach for every system; Memora highest at 5.32 percent BRT (Table 2).
- No defences were tested; they are listed as future work.

## What Engram borrows
BR and BRT are action-level, multi-session metrics that match MEM-INV-Bench's consequence framing. The retrieve, interact, write adapter harness over Mem0, Letta and others mirrors our adapter set, so a MemoryDojo-style cross-session run could be a secondary arm for H1 or H4 with C2 against C5 once code is released.

## What Engram does differently
MemoryDojo measures how vulnerable native memory systems are; Engram measures whether the write gate and read filter cut that. Poison arrives through tool observations, which map to Engram's tool provenance, not to model-claimed provenance.

## Risk to our claims
Letta's persistence through core memory (retrieval stays above 50 percent in later sessions, Fig. 6b) suggests a store-specific effect that could appear as store dependence in H4. Action: report H4 per store and expect Letta to be the hard case.

## Open question
Does an origin-bound write gate cut BRT to zero on A-MEM, or does the optimised payload route through an authorised write path?
