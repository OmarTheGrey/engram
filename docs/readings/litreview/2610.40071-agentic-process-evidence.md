## Claim
Agent sessions are ephemeral, so their reasoning, tool calls and accountable owner vanish when the session ends, and SDLC audit assumes a human made each decision. The authors propose Agentic Process Evidence (APE), a signed, tamper-evident, machine-readable attestation linking an agent session to its outcome.

## Method
Abstract only was read. APE follows the in-toto attestation style and is described as enabling policy-as-code control over agent processes, targeting supply-chain security, policy compliance and task alignment.

## Key numbers
None stated in the sources read.

## What Engram borrows
The packaging idea: an exported, signed statement per period or per session that binds decisions to an accountable actor, in in-toto/DSSE form (plan AB-CMP-1). It lands next to the audit export, not in the log schema.

## What Engram does differently
APE attests code-change outcomes. Engram attests memory decisions (allow, deny, retire, erase) with the policy id and reason, and the attestation is derived from a replayable log rather than collected from the agent.

## Risk to our claims
If APE or a similar format becomes the accepted agent-evidence standard, an Engram-specific report format could look parochial. Mitigation: emit a standard envelope (DSSE) with an Engram predicate type.

## Open question
Does the full paper define a predicate schema we can reuse, or only a concept?

Only the abstract page was read; the design, implementation and any evaluation are unverified.
