## Claim
The most governance-forward memory vendor sells audit, SSO, SCIM, BYOK, BYOC, SOC 2 Type II and a HIPAA BAA only on its Enterprise plan. Self-serve plans are credit-metered on ingestion size, not on retrieval.

## Method
Pricing page read in full. Flex is $125 per month (50,000 credits), Flex Plus $375 per month (200,000 credits), Free 10,000 credits, Enterprise custom with one-year API log retention. One credit is 350 bytes of episode; retrieval and storage cost zero credits; webhooks cost 1/8 credit. Graphiti repository checked with gh api: Apache-2.0, 32,972 stars, pushed 2026-11-20.

## What Engram borrows
The packaging shows buyer expectations: audit, SSO, BYOK and VPC are the enterprise gate. Custom entity and edge types (5 to 20 by plan) argue for typed memory kinds in policy.
