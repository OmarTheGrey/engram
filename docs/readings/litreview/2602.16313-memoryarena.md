## Claim
When a task is split into interdependent subtasks that run as separate sessions, so everything learned must pass through memory, every long-context model, memory agent and RAG method scores below 0.20 average success, and agents that saturate LoCoMo do not transfer.

## Method
701 task groups in four families, each decomposed into subtasks run as separate sessions: bundled web shopping from WebShop (150 groups, 6 subtasks), group travel planning from TravelPlanner (270 groups, 5 to 9), progressive web search from BrowseComp-Plus (221 groups, 2 to 16), and formal reasoning chains curated by PhD-level experts (40 math, 20 physics) (Sec. 3.1, Table 2). Memory starts empty; at each step the agent calls Retrieve over memory, past actions and observations, then acts; when a subtask ends, Update writes the trajectory into memory and the next session begins with only that memory (Sec. 3.2, Eqs. 2 to 4). Task agent GPT-5.1-mini; comparators are long-context models (GPT-4.1-mini, Gemini-3-Flash, Claude-Sonnet-4.5), memory agents (Letta, Mem0, Mem0-g, Mirix, ReasoningBank) and RAG (BM25, text-embedding-3-small, MemoRAG, GraphRAG) (Sec. 4, Table 3). Success is rule-based per family against human- or expert-verified keys (Sec. 4.2).

## Key numbers
- 701 task groups; average trace 57 action steps (Sec. 1, Table 1).
- All-task average success: text-embedding-3-small RAG 0.20 (best); Gemini-3-Flash 0.19; BM25, MemoRAG, GraphRAG 0.17; GPT-5.1-mini and Claude-Sonnet-4.5 0.16; Letta 0.14; Mem0 and Mirix 0.13; Mem0-g and ReasoningBank 0.12; GPT-4.1-mini 0.09 (Table 3).
- Group travel planning: success and progress 0.00 for nearly every method; bundled shopping 0.00 for all memory agents and RAG (Table 3).
- Formal physics reaches 0.46 for long-context agents, the highest family score (Table 3).
- Every method decays as subtask depth grows (Sec. 4.4).

## What Engram borrows
The Retrieve and Update interface is the same two-call shape as MERIT's `read` and `write`, confirming the `Adapter` contract in ADR 0013 is the right granularity for benchmark plug-in. The statement that single-session traces stay in context and multi-session traces are inaccessible is the cleanest definition of the episodic boundary the distiller (ADR 0012) works across: a procedure is only useful if it carries information over that boundary. MemoryArena is a candidate domain-general holdout for H5 in Kapoor's table, since its tasks shaped no policy.

## What Engram does differently
MemoryArena measures whether memory carries task state forward, with no notion of who may write or read. Engram's procedural condition stores validated workflows, not raw trajectories, and the thesis would report whether that abstraction loses state MemoryArena needs. Engram meters cost; MemoryArena reports none.

## Risk to our claims
Scores near zero leave no room for a governance effect. H5 here would compare 0.12 against 0.14 over 701 items, within noise, which is why it stays optional. The deeper risk is to the narrative: if procedural memory cannot move interdependent tasks, H5 must be scoped to tasks where a reusable workflow exists (tau2-bench, MERIT arcs).

## Open question
Plain embedding RAG beats every purpose-built memory agent here. Is the extra machinery in Mem0 and Letta losing state at Update, and would a HaluMem-style omission metric on stored items explain the gap?
