## Claim
Agents retrieve the evidence that a stored belief is outdated and then fail to act on it. On 400 implicit-conflict scenarios the best frontier model scores 55.2 percent overall, memory frameworks score 5 to 18 percent, and the failure is sharpest on premise resistance, where a query that presupposes the stale state is accepted. Write-time state adjudication with a predefined schema (CUPMem) lifts a GPT-4o-mini pipeline from 8.7 to 68.0 percent.

## Method
STALE has 400 expert-validated scenarios yielding 1,200 queries over more than 100 everyday topics, embedded in chronological haystacks of LongMemEval distractor sessions up to 150K tokens (abstract, Sec. 3.4). Conflicts are implicit by construction: Axiom 2 forbids any later utterance that explicitly negates or corrects the old belief (Sec. 3.2). Two types: Type I co-referential (same attribute, incompatible values) and Type II propagated (a new observation on a different attribute cascades to invalidate the old belief) (Sec. 3.3). Three probes: State Resolution (detect the belief is outdated), Premise Resistance (reject a query that presupposes the stale state), Implicit Policy Adaptation (apply the new state downstream without a cue). Pipeline: base state anchoring, adversarial generation by a Logic Attacker, LLM-judge QC, session packaging, human expert review (Sec. 3.4, Fig. 2). Models: GPT-4o-mini, GPT-5.4-nano, GPT-5.4, Gemini-3.1-flash-lite, Gemini-3.1-pro, Llama-3.3-70B, Qwen3.5-9B, Qwen3.5-27B, MiniMax-M2.5. Frameworks on a GPT-4o-mini backbone: LightMem, Zep, LiCoMemory, A-mem, mem-0 (Sec. 4.1). Judge agreement with humans 95.8 percent, kappa 0.9152 (App. E.3).

## Key numbers
- Overall accuracy: Gemini-3.1-pro 55.2, Qwen3.5-27B 31.3, Gemini-3.1-flash-lite 22.4, GPT-5.4 15.7, Qwen3.5-9B 14.6, GPT-5.4-nano 9.8, GPT-4o-mini 8.7, MiniMax-M2.5 5.5, Llama-3.3-70B 2.6 (Table 2, Sec. 4.2).
- Gemini-3.1-pro by probe: Type I SR 92.0, PR 30.0, IPA 71.0; Type II SR 69.0, PR 14.0, IPA 55.0 (Table 2).
- Frameworks overall: LightMem 17.8, mem-0 8.3, LiCoMemory 7.6, Zep 6.0, A-mem 5.1; only LightMem beats plain GPT-4o-mini at 8.7 (Table 2).
- LightMem diagnostics: new evidence retrieved 77.5 percent (SR/PR) and 67.8 percent (IPA); failure despite new evidence 56.1 (SR), 99.0 (PR), 78.6 (IPA) percent; old evidence ranked top-1 for IPA 25.5 percent; during construction old entries appear in top-3 in 60.5 percent of cases but only 3.3 percent are judged as needing an update (Table 3, Sec. 4.4).
- CUPMem on GPT-4o-mini: overall 68.0; PR 78.0 (Type I) and 75.0 (Type II); SR 91.0 / 89.0; IPA 32.0 / 43.0 (Table 2, Sec. 5).

## What Engram borrows
The three probes are a finer version of what the expired-validity and contradiction lints must achieve (ADR 0008): detect (SR), refuse a stale premise at read (PR), and serve the current value by default (IPA). Premise Resistance is a read-side property and belongs in the explanation (ADR 0009): when a query matches a superseded version, the explanation should carry the superseding version id so the model is told, not left to infer. The LightMem diagnostic that the update step judges only 3.3 percent of top-3 old entries as needing update is a direct measurement of why ADR 0005 makes supersession a plane rule rather than a store heuristic. Type II propagated conflicts are the case for a `lineage`-aware contradiction lint that walks related items, not only same-key items. STALE is a candidate for the LongMemEval update arm in ADR 0015 (B-series) because it isolates implicit updates, which LongMemEval does not.

## What Engram does differently
CUPMem's gains depend on a predefined state schema per attribute domain (App. A), which is a product decision Engram does not make; Engram's schema has validity and lineage but no attribute ontology, so Type II propagation is a model-based lint (H3's second tier), not a structural rule. Engram also runs the same benchmark across several stores (H4), where STALE tests one backbone per framework.

## Risk to our claims
Even with retrieved evidence present, frameworks fail 56 to 99 percent of the time (Table 3). If the model ignores a superseded marker that Engram puts in the explanation, the read-side half of H3 contributes nothing and only write-side supersession counts. The honest design is to measure PR with and without the explanation injected, as separate conditions.

## Open question
Premise Resistance is near zero for every model except Gemini-3.1-pro (Table 2). Is that an instruction-following property that a governed prompt can fix, or does it need the plane to rewrite the query? A step-0 pilot on 50 STALE items with and without the superseding version id in context would answer it.
