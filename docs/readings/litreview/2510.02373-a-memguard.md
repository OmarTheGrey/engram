## Claim
A validation layer outside the agent can catch poisoned memory without changing the agent: compare reasoning paths from related memories, and keep lessons from detected failures in a separate store consulted before action.

## Method
Consensus-based validation flags a memory whose reasoning path diverges from those of related memories. A dual-memory structure stores distilled lessons from detected failures apart from the main memory. Only the abstract page was read, so datasets and models are not named here.

## Key numbers
- Attack success rates cut by over 95 percent at minimal utility cost (abstract). A search summary says over 97 percent in the EHRAgent scenario; not verified in the paper.

## What Engram borrows
The separate lessons store maps to a quarantine scope: items a lint flagged go to a scope the read filter does not serve, instead of only being retired. Consensus can live only as an injected model lint, because the plane makes no model calls.

## What Engram does differently
Engram decides at write time from origin, not from agreement among memories. Origin-Bound Authority (2606.24322) argues content and consensus defences can be laundered.

## Risk to our claims
Forged Reasoning (2607.05029, abstract only) reports that self-referential reinforcement defeats consensus defences including A-MemGuard. That supports a deterministic origin gate, and also says Engram's model lints are no substitute for it.

## Open question
Is consensus meaningful for fact-based items? A search summary reports a paper saying it is not applicable there.

## Notes
Use as an H1 baseline only if its code runs offline with a scripted model.
