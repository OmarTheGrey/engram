## Claim
Distilling short reasoning strategies from both self-judged successes and self-judged failures, and retrieving them at test time, beats memory that stores raw trajectories or only successful routines, and spending more test-time compute on diverse trajectories produces better memory.

## Method
Each memory item has a title, a one-sentence description, and content of one to five sentences of reasoning steps or pitfalls, abstracted away from specific sites or queries (Sec. 3, App. A.1). An LLM judge with the same backbone at temperature 0 labels each trajectory success or failure without ground truth; successes yield strategies and failures yield preventative lessons, with at most three items per trajectory (Figure 9, Figure 10, App. A.2). Consolidation is plain addition with no pruning or merging. Retrieval embeds the query with gemini-embedding-001, uses cosine similarity, defaults to top-1, and puts items in the system prompt. Memory-aware test-time scaling (MaTTS) generates k trajectories in parallel with self-contrast, or refines one sequentially; k = 5 in the main runs. Backbones Gemini-2.5-Flash, Gemini-2.5-Pro, Claude-3.7-Sonnet; BrowserGym ReAct agent with 30 steps and temperature 0.7; mini-SWE-Agent for code. Benchmarks WebArena (684 instances, Map excluded), Mind2Web (1,341), SWE-Bench-Verified (500). Baselines No Memory, Synapse, AWM.

## Key numbers
- WebArena overall SR / average steps, Gemini-2.5-flash: No Memory 40.5 / 9.7, Synapse 42.1 / 9.2, AWM 44.1 / 9.0, ReasoningBank 48.8 / 8.3, plus MaTTS 51.8 / 7.9 (Table 1).
- Same, Gemini-2.5-pro: 46.7, 47.7, 47.6, 53.9, 56.3; Claude-3.7-sonnet: 41.7, 42.6, 40.8, 46.3, 48.8 (Table 1). Gains over No Memory: +8.3, +7.2, +4.6 (Sec. 4).
- SWE-Bench-Verified resolve rate / steps, Gemini-2.5-flash: No Memory 34.2 / 30.3, ReasoningBank 38.8 / 27.5; Gemini-2.5-pro 54.0 / 21.1 to 57.4 / 19.8 (Table 2).
- Mind2Web task SR, Gemini-2.5-flash: cross-task 3.3 to 4.8, cross-website 1.7 to 2.3, cross-domain 1.0 to 1.6 (Table 3).
- Failures help: on Shopping, ReasoningBank 46.5 with successes only to 49.7 with failures; AWM falls 44.4 to 42.2 when given failures (Sec. 4.3).
- Judge accuracy 72.7 percent on WebArena-Shopping with Gemini-2.5-flash; simulated judge accuracy between 70 and 90 percent changes little (Sec. 5).
- Cost: 53,055 tokens per task against 50,847 for No Memory, about 4.3 percent more, for about 20.5 percent gain (Table 5).

## What Engram borrows
Failures carry signal: this is the evidence behind ADR 0012's use of abandoned pi branches and branch_summary entries as negative evidence in induction. The judge audit becomes protocol: before any Distill run, measure judge accuracy on a labelled sample, as ADR 0015 already does for benchmarks. The title, description, content triple is the shape of a procedure's retrieval description. Steps per task is the H5 efficiency metric.

## What Engram does differently
ReasoningBank stores declarative strategies, not executable procedures, and has no lifecycle: memory is append-only with no pruning, no validation beyond the judge, no retirement. Engram keeps AWM-style procedures (strategies are out of v1 per ADR 0012), admits by replay, tracks success, and retires. ReasoningBank's gains are inside one agent; Engram measures a plane above the store.

## Risk to our claims
ReasoningBank beats AWM on every backbone, and with Claude-3.7-sonnet AWM scores below No Memory (40.8 against 41.7, Table 1). Engram's induction is AWM, so the ungoverned baseline may itself be weak or negative on some providers, and a positive H5 could be "governance fixes a weak method" rather than "governed procedural memory is net positive". Mitigation: H5 is the paired difference between governed and ungoverned with the same induction, and the No Memory condition is reported next to both on all three providers.

## Open question
Append-only memory still improves across a stream of 684 tasks. Does retirement add anything on streams this short, or does it only matter under environment change? The GitLab migration in SKILL.nb is where retirement should show; the plain stream may not.
