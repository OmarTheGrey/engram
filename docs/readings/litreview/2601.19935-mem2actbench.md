## Claim
Memory should be tested by whether an agent applies remembered preferences and task state when filling tool parameters, not by whether it can recite them; on that test seven memory frameworks cluster at high tool accuracy but low parameter F1, and retrieval misses are the main failure.

## Method
Sessions merge ToolACE (8,000 samples processed), BFCL v3 (live, parallel, multi-turn) and OASST1 rank-0 responses as noise, giving 2,029 sessions of about 12 to 13 turns and 400 memory-dependent tool-use tasks (Sec. 3.2, 3.4.2, Table 1). An LLM parameter verifier and a solvability discriminator filter tasks; human validation reports 96.5 percent for fact extraction, 86.7 for conflict resolution and 91.3 for memory dependency (Sec. 3.6, Table 2). Seven frameworks share a Qwen2.5-Instruct backbone at 7B, 32B and 72B with BGE-M3 embeddings: LTMemory, SCM, Generative Agents, MemTree, Mem0, LangMem, A-Mem (Sec. 4.1). The gold tool is supplied, so the task is parameter grounding; metrics are parameter-level F1, BLEU-1 and Tool Accuracy (correct tool plus exact parameters), all deterministic (Sec. 4.1).

## Key numbers
- Qwen2.5-72B, F1 / BLEU / Tool Accuracy: A-Mem 35.93 / 67.93 / 93.25; LTMemory 35.32 / 67.93 / 92.00; MemTree 33.21 / 68.17 / 94.25; Mem0 28.95 / 66.47 / 96.75; LangMem 24.01 / 63.06 / 96.25; SCM 22.73 / 62.04 / 96.25; Generative Agents 22.38 / 62.58 / 95.50 (Table 3).
- Mean F1 rises from 20.4 at 7B to 28.9 at 72B, diminishing past 32B (Sec. 4.2).
- Oracle retrieval F1 53.8 vs 30.7 for the best passive retriever (hybrid, k 5) (Sec. 5.1, Table 4).
- Evidence in the 25 to 50 percent history bin hurts most: A-Mem falls from about 36 to about 25 F1 (Sec. 5.2, Figure 3).
- With hard negative tools, tool selection falls from 94.50 percent (N 1) to 69.75 (N 5) (Sec. 5.4, Table 5).

## What Engram borrows
The oracle gap (53.8 vs 30.7) separates what the store holds from what the read path returns; Engram reports the same split per condition from the explanation record (ADR 0009), so H1 can say whether enforcement changed admission or ranking. Parameter-level F1 on executed tool calls is a cheaper cousin of MERIT's ignore-rate tracer and joins the B-card metrics as a secondary action metric. The mid-history loss is a second data point for the placement rule taken from Lost in the Middle.

## What Engram does differently
Mem2ActBench generates tool calls offline with no execution; Engram's action benchmarks execute against state. Mem2ActBench ranks memory frameworks on one Qwen backbone; Engram holds the framework fixed, ranks policies, and uses three hosted providers (H4).

## Risk to our claims
Tool accuracy clusters at 87 to 97 percent across all frameworks, so structural correctness is solved and the variance is semantic retrieval. If the same holds under Engram's conditions, a write gate, which affects what is stored, may show no effect where storage is not the bottleneck. Mitigation: Mem2ActBench stays optional and is not pre-registered for any hypothesis.

## Open question
Human validation of conflict resolution is only 86.7 percent. If about one in eight update-type items has a disputed label, is the update subset usable for ADR 0005 testing, or does Engram run its own 50-item audit first?
