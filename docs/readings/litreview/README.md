## What the review changes for Engram

Distilled from the 65 notes. Each line names the notes that force it.

### Novelty claims
- "First deterministic policy on memory reads" is no longer safe. A production multi-tenant memory service with scopes, a trust ladder and provenance exists (2606.24535), and typed deterministic admission has been measured on the read side (2610.11188). What remains defensible: a store-agnostic plane over existing stores, a replayable append-only event log mirrored into the harness session, and a measured governance tax across stores and models. Rewrite the novelty paragraph in the proposal and the overview accordingly.
- Write-time origin binding is proven necessary and sufficient against laundering (2606.24322, 2609.01836). Engram's provenance comes from the harness, not from a judge, which is the difference to state against GhostWriter/AM-Sentry (2607.06595).
- MemOS's MemCube is the nearest published item schema and its MemGovernance includes calling context as a permission input (2507.03724). Engram's policy input lacks calling context; add it or justify its absence in ADR 0006.

### Hypotheses
- H1. The instruction hierarchy still leaks after training (2404.13208), and executors act on false authority 98.6 percent of the time (2609.01836). The action metric should be MERIT's ignore rate (agents act on a correctly retrieved value about 55 percent of the time, 2609.05441), not recall alone.
- H2. Every governance paper reports a large utility cost: a cited-source gate halves legitimate action (2609.01836); typed admission raises personalisation failure 5 to 8 points (2610.11188); long-context prompting already reaches MGS 80.1 on GateMem (2606.18829), and long-context baselines beat memory systems on three of four MemoryAgentBench competencies (2507.05257). Report the tax per memory class and per benchmark, keep the long-context condition, and expect no knee on recall benchmarks.
- H3. Contradiction detection accuracy is low even for strong models (2403.08319); cosine similarity cannot separate contradiction from duplicate (AUROC 0.59, 2606.26511); the expired-validity lint fires only on keyed items and keying covers about 44 percent of prose (2606.26511, 2610.10265). Report deterministic and model-based lints separately and bound H3 by the keyed fraction.
- H4. MemGPT's gains collapse on weaker function callers (2310.08560) and Agent Zero Memory shows a 12.5 point backbone span on LoCoMo (2608.29606). State H4 as invariance of the plane's decisions, not of agent scores, and report per model.
- H5. Ungoverned skill libraries drift below the no-skill floor and retirement recovers it (2605.19576); rule-based induction equals model induction in AWM (Table 5, 2409.07429); AWM scores below no memory on one backbone (2509.25140); verified experience on coding tasks helps 1 to 4.5 points with intervals crossing zero (2609.23570). H5 is the governed-versus-ungoverned delta, with an ungoverned utility-weighted procedural baseline (2602.22406), reported per provider.

### Design
- Supersede, never overwrite, is confirmed from three directions: A-MEM's lineage-free evolution is worth about 15 F1 on temporal tasks and is exactly what must be auditable (2502.12110); Zep's four timestamps are the model (2501.13956); 24 of 100 PersonaMem failures are missed preference updates (2504.14225).
- Retire by event, never delete in place: selective repair fails on benign preservation (2607.27080); tenure crossover punishes eviction (2607.21962); no memory system passes more than 1.5 percent of forget requests (2610.18052). Verified forgetting is the one governance primitive Engram must address honestly (2604.16548).
- Replay admission must check outcome, not completion: SkillWeaver's "verified" meant "runs without exception" (2504.07079); Voyager's critic is one pass with no retirement (2305.16291). MSCE activates after one success with a Beta-smoothed reliability score (2607.16621); SKILL.nb uses Wilson bounds and keeps retired skills for rollback (2606.08049). Engram's k of n is more conservative and must say why.
- Calling context and namespace routing belong in the read path: namespace routing lifts recall 0.432 to 0.533 at 98 percent fewer similarity calls (2610.07309); position matters (2307.03172), so explanations carry rank.
- Compaction output is the lowest-trust write channel (C3 in 2606.04329); pi `compaction` entries map to it directly.

### Evaluation
- Benchmarks to add to the pin list: VibeMemBench (2609.23570), STALE (2605.06527), EAL-Bench (2609.01836), Bemula (2610.18052), MEM-INV-Bench (2606.24322).
- Plug-in reality: LongMemEval and MERIT accept an external system cleanly; MemoryAgentBench and tau2-bench need a method file or an agent subclass inside their repo; GateMem and MPBench have no verifiable code release as of 2026-10-17 (step 0 task S0.6).
- LoCoMo is a smoke test only: 6.4 percent of its key is corrupt and an LLM judge accepts 62.81 percent of wrong answers (audit cited in 2607.21962). HaluMem shows Mem0 omits 74 percent of updates at 160k tokens, so governed and ungoverned conditions converge on the long-horizon arm for extractor stores (2511.03506).
- Pre-register before the first run; Holm needs no independence, which matters because bootstrap p-values across H1 to H5 are dependent (methods notes).
