## Claim
Memory should be judged by whether a remembered fact changes what a tool-using agent does and what that costs; under that measure the memory implementation moves success by up to 60 points, agents ignore a correctly retrieved value about half the time, and full replay is never economical.

## Method
Episodic tool-use tasks run in three seeded SQLite worlds: retail support, IT operations, personal assistant (Sec. 3.3). Arcs of four to six episodes plant, update and probe facts; a leak check guarantees the gold value is absent from the probe inputs, and delta scoring counts success only when a checker predicate flips from false to true during the episode (Sec. 3.2). Six conditions share one `write(episode)` and `read(context)` interface: C0 none, C1 full replay, C2 embedding retrieval, C3 LLM summary, C4 structured fact store with update-on-write, C5 hybrid (Sec. 3.4). Every memory-side call is metered (Sec. 3.5). Hypotheses were committed before runs; analysis is paired bootstrap, 10,000 resamples clustered by arc, Holm-corrected (Sec. 3.6).

## Key numbers
- 23,440 scored episodes, $42.57 (Sec. 4); README says $44.82.
- C0 scores 0.000 on dependent tasks in all nine cells (Sec. 5.1).
- Hard tier, D1 / D2 / D3: C2 0.70 / 0.35 / 0.45; C4 0.95 / 0.75 / 1.00; C3 1.00 / 0.70 / 1.00 (Table 1, Sec. 5.2).
- Ignore rate: latest value in C2's retrieved block in 55 probes, acted on in 30, about 55 percent; human audit 93 percent agreement, kappa 0.63 (Sec. 5.4).
- Largest seed gap 0.45 (C2, D1-hard, per seed 0.45 / 0.90 / 0.75) (Sec. 5.7).
- Per-episode cost D1-easy: C0 $0.00046, C4 $0.00066, C1 $0.00126; full replay 2.7 to 3.9 times worse per dollar than the per-domain best (Sec. 5.6).
- Corruption: hybrid C5 +0.25 stale-memory harm at rate 0.3, Holm p 0.030, the only significant harm (Sec. 5.5, Figure 4).

## What Engram borrows
The metering discipline lands in ADR 0017: every memory operation's tokens and dollars go into the cost ledger so the H2 knee is a derived curve. The leak check and delta scoring become the acceptance test for any task Engram adds to its own fixtures. Paired bootstrap clustered by arc with Holm is already ADR 0016; MERIT is the precedent. The ignore-rate tracer (string containment on executed tool-call arguments) is adopted as the H1 action-level metric, and is the reason ADR 0009 explanations are injected into context. The stale, contradiction and distractor modes become seeded faults in `fixtures/faults/` for L2.

## What Engram does differently
MERIT varies the memory implementation with no policy. Engram holds the implementation fixed per adapter and varies the policy above it. MERIT's corruption is injected by the harness; in Engram the write gate is supposed to refuse it, so the sweep tests the gate. MERIT evaluates reimplementations; Engram runs Mem0 and Letta through adapters.

## Risk to our claims
A seed gap of 0.45 on one cell means three seeds may not bound the H1 effect on hard-tier items. If enforced governance sits inside the seed noise of instruction-only on MERIT, H1 fails on the one benchmark that measures action. Mitigation: the ADR 0016 stopping rule adds seeds on a cell whose interval straddles zero.

## Open question
A Claude Opus 4.8 spot-check scored 0.75 under full replay, attributed to provenance skepticism (Sec. 7). Does an explanation naming the source and policy rule raise the act-on rate for stronger models, or lower it?

## Notes
Dataset: three synthetic domains, 10 arcs by 5 episodes per cell, easy / medium / hard ladder, dependent ratio 0.5. Judge: deterministic end-state checker; LLMs appear only as simulated users and memory-side calls. Plug-in: implement `write` and `read` as in `merit/memory.py`; LiteLLM, any OpenAI-compatible endpoint; no judge changes. Licence: MIT (README). Traces for every run under `runs/`; `HYPOTHESES.md` is the preregistration. Models: gpt-4.1-mini (three seeds), GPT-4.1 and Claude Haiku 4.5 (one seed each). Limitations (Sec. 7): checkers may miss real success notions, single annotator, one representative per implementation, costs tied to mid-2026 pricing.
