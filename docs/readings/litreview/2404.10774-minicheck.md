## Claim
Small fact-checkers (the best is 770M parameters) trained on GPT-4-synthesised data reach GPT-4-level accuracy on checking whether a claim is supported by a grounding document, at about 400 times lower cost.

## Method
Synthetic training data with hard multi-sentence factual errors, a Flan-T5, RoBERTa and DeBERTa family, and a new benchmark, LLM-AggreFact, that merges existing grounding datasets. Only the abstract page was read, so the data recipe and per-dataset results were not.

## Key numbers
- 770M parameters for MiniCheck-FT5; "GPT-4 accuracy" at "400x lower cost" (abstract).
- No accuracy figures in the sources read.

## What Engram borrows
A local checker for the unsupported-claim lint (card L3): the claim is the hypothesis, the source item (provenance.ref) the premise. MiniCheck-Flan-T5-Large is MIT on its model card. The Bespoke 7B variant shows no licence tag on the Hub API and is treated as not absorbable until checked.

## What Engram does differently
Engram's lint today has only a model-call tier. A local checker would be a further tier with its own events and a pinned model hash, not a replacement.

## Risk to our claims
Accuracy is measured on grounding documents, not on short memory items, so the transfer to Engram's fault set is unmeasured. We would measure it on the L2 fault set before any claim.

## Open question
Does MiniCheck beat the model lint's precision on the L3 pilot items?
