# E2.11 Trust floors in the write path and in retention

Status: open.

From `docs/tasks/absorb-plan.md`, pull request 20 of 30 (research plans R-023, R-024 in `docs/research/absorb/long-list.md`). Lane: research. Week: W13. Effort: M. Read AGENTS.md, the plan's entry for this card and `docs/conventions/absorption.md` before starting.

Goal: With the policy's trust options on: a write whose actor attests no source lands at the least trusted kind, and no write, eviction or retire by a less trusted source changes or removes a more trusted active item unless its owner acts. With them off, nothing changes.

Why: This is the fix for whatever card E2.7 confirms. If a caller with no attested source can claim to be a person typing, the provenance model the thesis rests on has a hole. If an agent's write can evict or overwrite a person's item, source isolation is weaker than ADR 0007 says.

Steps:

1. Start from E2.7's findings. A gap it refuted is dropped from this card.
2. The floor (`trust.unattested_floor`): in `withPlaneProvenance`, an actor with no source gets the least trusted kind and a reason, instead of the caller's claim. Each surface (CLI, MCP, HTTP, pi extension) declares its source, so only a library caller that names none is floored.
3. Protection (`trust.protect_trusted`): `evaluateWrite` denies a rewrite or retire of a more trusted active item by a less trusted source with reason `engram/write/downgrade`, and the retention victim order never evicts a kind more trusted than the writer that triggered the eviction. The owner acting as a user is exempt.
4. Both off in the H1 to H4 presets, so no registered number moves, and on in a new preset. A test asserts each registered preset's decisions are byte-identical.
5. The eighth invariant in the always-on file, with the oracle extended, and E2.7's `it.fails` tests turned into plain tests under the options. The invariants file changes only with a second reviewer (`docs/conventions/testing.md`).

Absorbs (mode per ADR 0037):

- dent8 (Apache-2.0 or MIT, port): the authority checks of its ADR 0011 and `state.rs`, as a design.
- Veracium (MIT, port): the unattested-write floor design.
- mentisdb, Mnemowall (MIT, Apache-2.0, idea): audience rules and trust at a version.
