# B10 The cassette proxy for outside harnesses

Status: open.

From `docs/tasks/absorb-plan.md`, pull request 6 of 30 (research plans R-022 in `docs/research/absorb/long-list.md`). Lane: research. Week: W9. Effort: M. Read AGENTS.md, the plan's entry for this card and `docs/conventions/absorption.md` before starting.

Goal: A loopback server in `@engram/model` that speaks the OpenAI chat-completions API and serves every request through the existing cached, seeded call, so a Python harness obeys rules 6 and 7 without being ported.

Why: MERIT and tau2-bench call their models through LiteLLM, outside the cached call. H2 needs MERIT and H5 needs tau2. ADR 0036 decided on this proxy on 2026-11-20 and no card existed. Nothing mature exists to absorb: the three open cassette proxies the sweep found have at most two stars.

Steps:

1. `proxy.ts`: a Node `http` server bound to 127.0.0.1, one route, `POST /v1/chat/completions`. The harness, item, condition, preset, store and seed come from the proxy's start-up configuration and per-request headers; with the model and the prompt hash they form ADR 0017's key.
2. Modes as the runner has them: replay by default, a miss is an error returned to the caller and recorded; record only under the live flags; refused under `ENGRAM_OFFLINE=1`.
3. Every call's usage goes to the same ledger the runner writes (card RV1), so cost accounting needs nothing new.
4. Tool use passes through: a request's `tools` and `tool_choice` and a reply's `tool_calls` are carried unchanged and are part of the prompt hash, since tau2-bench is a tool-use harness and sends tool definitions with its calls. If the cached call's types cannot carry tool definitions, extending them is this card's work.
5. Streaming and embeddings requests return 501 with a reason, until a harness card needs one.
6. A helper that a research config uses to refuse a harness endpoint that is not the proxy. ADR 0036 states the limit: a configuration check, not a network control.
7. Tests on the scripted model: a replay where a miss is an error, a second run that makes zero new calls, the same key as the runner for the same call.

Absorbs (mode per ADR 0037):

- vcrpy (MIT, idea): the record-mode vocabulary (none, once, new episodes, all).
- LiteLLM (MIT, idea): a response header that says whether the reply was a cache hit.

Files: packages/model/src/proxy.ts (new), packages/model/src/index.ts, packages/model/test/proxy.test.ts (new), Makefile and AGENTS.md with CLAUDE.md if a command is added, docs/log/

Depends on: none (ADR 0036 is accepted; RV1 is merged)

Decision: none.

Acceptance: `make test-one T=packages/model/test/proxy.test.ts`: a miss is an error, and a second run makes zero new calls

Risks: A key that leaves out the seed or the prompt hash breaks rule 7 silently: the same-key test guards it. No new dependency.

Out of scope: any harness (cards B7 and B11); the Zenodo deposit and fetch script of ADR 0036; imports from `packages/bench` or `packages/runner` (ADR 0033); anything in another package; schema changes unless the card says so (AGENTS.md rule 5)
