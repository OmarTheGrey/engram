Goal: A pure classifier in core of known harness memory locations and a bounded walk in the CLI that counts, per harness and kind, the files outside every configured store root, with size and time and never content; `engram doctor` warns on them.

Why: Gate D measures zero violations on the plane, with members' native memory path stated as outside it (lead-decisions item 33). Discovery counts what that statement leaves out, so the dogfood report can say how much it is.

Steps:

1. A dated table of locations (Claude Code auto memory and `CLAUDE.md`, Codex `AGENTS.md` and memories, Cursor rules), each row with its documentation link.
2. `classifyHarnessMemory(path, head, home)` in core, pure.
3. `engram discover [--root] [--home]` with a bounded walk; counts and paths only (rule 12).
4. One doctor check, a warning, never a failure.
5. Fake-home fixtures.
