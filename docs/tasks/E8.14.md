Goal: A small kit that makes an adapter for an agent framework thin, and the first adapter built on it: a Vercel AI SDK middleware that reads through the plane before a model call and writes only through explicit tools.

Why: Engram governs memory for pi, and for Claude Code and Codex over MCP. Most agents are built on a framework with its own memory seam. One shared kit keeps each adapter to a page, and the AI SDK middleware is the smallest and the quickest to demonstrate.

Steps:

1. In core: a read by id and a list of the scopes an actor can see, both through the same gate as `Plane.read`, with their routes and `make api`.
2. `packages/kit`: what every adapter repeats. An actor fixed at construction (never taken from model output), a mapper from a framework's namespace to a scope, and a typed rejection that carries the decision event.
3. `packages/ai-sdk` (`@engram/ai-sdk`): a language-model middleware that adds governed recall to the prompt, and two tools, remember and recall, that call the plane.
4. A conformance test for adapters built on the kit: no path reaches a store except through the plane, and a denied write surfaces as the typed rejection.

Absorbs (mode per ADR 0037):

- Vercel AI SDK (Apache-2.0, depend): `@ai-sdk/provider`, a peer dependency with the development version pinned exactly.
