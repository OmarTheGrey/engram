# E8.1 HTTP server: a thin TypeScript API over core, with generated OpenAPI

Status: open.

Rewritten for ADR 0001: the v1 card was a FastAPI app; the server is now a thin TypeScript HTTP layer over the same core, and OpenAPI is generated from its route definitions.

Goal: routes for items, events, policy, lint, simulate, distill and explain (`/api/v1/...`, `docs/architecture.md`); every handler calls core and holds no policy logic; OpenAPI is generated from the route schemas, which reuse the Zod contract.

Files: `packages/server/src/`, `packages/server/test/`, `sdk/openapi.json`

Depends on: E0.3, E1.1

Acceptance: contract tests hit every route against the fake adapter; `make api-check` passes with the OpenAPI document included

Out of scope: authentication, the UI.
