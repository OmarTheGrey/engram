Goal: A small open natural-language-inference model scores candidate pairs locally, between the deterministic lints and the model-based contradiction lint. Only the uncertain band goes on to the model. The result is how many model calls the tier saves and what it costs in recall.

Why: The decisions of 2026-11-20 made the model-based tier H3's main test, and that tier pays a model call per candidate pair: 95,217 on the full set. A cross-encoder scores a pair in milliseconds on a laptop.

Steps:

1. First, a determinism check: the same pairs scored on two machines, compared to a stated tolerance. If scores differ beyond it, every score is treated as a cached model call and never recomputed, and the log says so.
2. The scorer is an injected function with the shape of `ModelCall`: core defines the type and the tier, and imports nothing.
3. The scorer itself lives in `packages/model`: `cross-encoder/nli-deberta-v3-small` (Apache-2.0) through ONNX, its weights fetched by sha256 into `.engram/upstream`, never committed. Every score is cached under a key of the model's hash, the runtime's version and the pair's hash (rules 6 and 7).
4. The tier: above the policy's upper threshold a pair is flagged, below the lower it is dropped, and between them it goes to the model lint. A scripted scorer for unit tests.
5. `h3_lint_delta.py` reports the tier beside the model tier on the fixture: calls saved, precision and recall per fault class.

Absorbs (mode per ADR 0037):

- cross-encoder/nli-deberta-v3-small (Apache-2.0, depend): the model, pinned by revision and sha256.
- transformers.js or onnxruntime-node (Apache-2.0, MIT, depend): the runtime; whichever runs on Windows without a native build step is chosen in the spike.
- MELD (paper, idea): NLI as a merge and contradiction signal.
