# X16 Gate mutation audit: a frozen mutant set for every invariant

Status: planned, absorb plan 2.

From `docs/tasks/absorb-plan-2.md`, pull request 5 of 30 (research plans R-042 (GH-57, AB-FRM-5) in `docs/research/absorb/long-list.md`). Lane: research. Week: W10 (after H1's `MERGE=4`). Effort: M. Read AGENTS.md, the plan's entry for this card and `docs/conventions/absorption.md` before starting.

Goal: A frozen set of hand-written mutants of the write gate, the read filter, retention, promotion and offboarding, each paired with the one test that must kill it, run by a script that reports killed and surviving mutants per invariant.

Why: Several cards checked by hand that a test bites. A durable, regenerated number per invariant is stronger Part I evidence than a review note.

Steps:

1. `fixtures/mutants/`: each mutant one exact substitution, its file, and the test that must fail.
2. The script's guards: the baseline passes, the replace string matches once, the mutant loads, the tree is clean after.
3. Each mutant applied in a temporary copy, never in the working tree.
4. The result lists survivors; every invariant has at least one killed mutant.
5. The audit serves no hypothesis: by the brief's rule its result takes the `h1-` prefix `test_prereg.py` requires and carries `"hypothesis": "none"`; the results page lists it apart from H1's results.
