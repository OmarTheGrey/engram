Roadmap v1's card was "Session recorder for tau2 tasks and a repository task set; sessions stored as episodic items", files `procedures/record.py`, acceptance "fifty sessions recorded with task ids". Under ADR 0001 the paths are the TypeScript layout in AGENTS.md.

Goal: A pi session is recorded as an episodic item the plane governs, with its task id, its outcome and its abandoned branches kept as negative evidence.

Why: Distill learns procedures from past sessions, and pi already keeps each session as an append-only tree. The recorder is the input every later Distill card needs.

Steps:

1. A pure parser in core: pi session JSONL text to an episode (the steps on the final branch, the tool calls and results, the outcome, and each abandoned branch with the point it was left).
2. A recorder outside core that reads session files and writes each episode through `Plane.write` as an episodic item, by an actor whose source the harness sets.
3. Scrub before storing: the redaction table already in `packages/core/src/plane/bypass.ts` runs over every episode, and a session that still matches is held, not stored (rule 12).
4. Fifty scripted fixture sessions under `fixtures/sessions/` (it holds two today), synthetic, with task ids, written from a seed by a generator that `make fixtures` runs, since fixtures are regenerated only that way. Real tau2 sessions arrive with card B11.

- OpenAI Agents SDK (MIT, idea): the span vocabulary of its traces, for naming an episode's steps.
