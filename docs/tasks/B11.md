# B11 tau2-bench through the plane and the proxy

Status: open.

From `docs/tasks/absorb-plan.md`, pull request 11 of 30 (research plans R-033 in `docs/research/absorb/long-list.md`). Lane: research. Week: W11. Effort: M. Read AGENTS.md, the plan's entry for this card and `docs/conventions/absorption.md` before starting.

Goal: tau2-bench runs as an external process with its agent and user-simulator calls served by the cassette proxy and a memory seam through the plane, under conditions C1, C2 and C5, and a fixture slice replays offline with zero new calls.

Why: H5 is registered on tau2-bench and nothing drives it. Without this card H5 cannot run and Distill has nothing to be measured on.

Steps:

1. A spike first: prove that tau2 at the pinned `v1.0.1` routes both its agent and its user-simulator calls to the proxy through its LLM arguments, and that the seed arrives at the proxy. Log the outcome before building more.
2. A launcher as in card B7. tau2 does not test memory by itself (PINS.md): the memory seam is where a memory layer is inserted, and the card states exactly where.
3. The reward is tau2's own database-state hash, read from its output; no judge of ours.
4. A fixture slice (a few tasks of one domain) with committed cassettes, including the user simulator's.
5. The usage ledger gives the cost. Note in the log how much the user-simulator cassettes add to a deposit.

Absorbs (mode per ADR 0037):

- tau2-bench (MIT, depend): the harness as an external process at tag `v1.0.1`; nothing copied.
- LiteLLM (MIT, depend): only its client-side `api_base` override, inside tau2's own environment.

Files: packages/bench/src/tau2/ (new), packages/bench/test/tau2/ (new), packages/bench/PINS.md (the pin's notes only), research/configs/b11-tau2-fixture.json (new), fixtures/cassettes/b11-tau2-fixture/ (new), Makefile, AGENTS.md and CLAUDE.md, docs/log/

Depends on: B10

Acceptance: `make bench BENCH=tau2` replays the slice twice from cassettes, the second run with zero new calls

Risks: The spike may show tau2 calls a model somewhere the arguments do not reach: then the card stops and reports, since a patched harness is no longer the pinned one.

Out of scope: H5's runs (card X11); the move to the repository's newer head, which is a different benchmark (PINS.md); anything in another package; schema changes unless the card says so (AGENTS.md rule 5)
