# E2.7 Counterexample tests for the two suspected trust gaps

Status: done on branch e2-7-trust-counterexamples, awaiting review. Paths: packages/core/test/counterexamples/trust.test.ts, docs/log/2026-11-21-e2-7-*.md.

From `docs/tasks/absorb-plan.md`, pull request 3 of 30 (research plans R-003 in `docs/research/absorb/long-list.md`). Lane: research. Week: W8. Effort: S. Read AGENTS.md, the plan's entry for this card and `docs/conventions/absorption.md` before starting.

Goal: Each suspected trust gap is proved or refuted by a committed test, before anything is changed: (1) a write whose actor names no source keeps the provenance kind its caller claims; (2) a budget eviction, a retire or a rewrite by a less trusted source removes or changes a more trusted item.

Why: The source-level readers of the GitHub sweep found both by reading, not by running. The first is documented behaviour (ADR 0004, decision D4: `withPlaneProvenance` in `packages/core/src/plane/write.ts` lets the caller's provenance stand when the actor has no source); whether it is a gap depends on which surfaces can reach the plane without a source. The second is unconfirmed.

Steps:

1. One new test file of characterisation tests: each case is a plain test that asserts what the plane does today, named for the gap and carrying its finding id. A confirmed gap is pinned by a test that shows it, a refuted one by a test that shows the safe behaviour, and the suite is green either way. (`it.fails` is not used: it turns red when a gap is refuted, and passes on any unrelated throw.)
2. Each case asserts the specific outcome: the decision, the reason id and the item's kind afterwards, never only that something threw.
3. The lattice: for each pair of the seven provenance kinds as writer and victim, and each of rewrite, retire and budget eviction, assert that the less trusted writer does not change or remove the more trusted active item unless the owner acts.
4. The floor: a write through `Plane.write` by an actor with no `source`, claiming kind `user`. Then list, with file and line, how each surface sets the actor's source. Known before the card starts: the CLI, the MCP server, the Claude Code hook and the pi extension set it themselves; the HTTP API takes the whole actor, source included, from the request body (`packages/server/src/routes.ts`), so an HTTP client may send none or any.
5. One `finding` log entry per gap with its reproduction command, whether confirmed or refuted. A refuted gap is removed from card E2.11.
6. Check whether a confirmed gap can change a registered H1 to H4 number, and say so in the entry. Report, do not hide.

Absorbs (mode per ADR 0037):

- dent8 (Apache-2.0 or MIT, idea): the exhaustive kind by kind by operation lattice as a test shape.
- Veracium (MIT, idea): the expectation that an unattested write lands at the least trusted kind.
