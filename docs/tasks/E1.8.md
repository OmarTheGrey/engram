Goal: ITF traces generated from `specs/commit.qnt`'s `good` module are replayed step by step on real Plane handles over one log, and the state after each step equals the trace's.

Why: Card E1.5 checked the protocol's model; nothing checks that the code follows the model. Trace replay joins them, and card E1.7's fix is then checked on both sides.

Steps:

1. A small ITF reader in the test tree (the `@firfi/quint-connect` package stays unusable).
2. A driver mapping each action of the model to Plane calls on N handles, with the injected clock.
3. A state comparison per step: the projection, the log's offboarding marks and the store records.
4. At least 200 traces committed under `specs/traces/`, regenerated by `make verify-spec`.
5. The two known gaps reproduced as the model states them.
6. Core's vitest project uses the default include (`packages/core/vitest.config.ts`), so `test/model/` is picked up; confirm the test count printed.
