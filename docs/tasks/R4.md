Goal: One file maps each governance claim Engram makes to the test that proves it and to the legal obligation it would be evidence for, and a script turns it into the thesis table and fails when a named test does not exist.

Why: The thesis claims governance. An examiner can fairly ask which claim is backed by which test, and which obligation of the EU AI Act or the GDPR it bears on. Today the answer is spread over the whole test suite.

Steps:

1. `research/configs/crosswalk.json`: one row per claim (for example, "a read never returns an item outside the reader's scopes and grants") with the test file and test name that proves it, the invariant if there is one, and the obligation it gives evidence for, with the article and paragraph of the primary text.
2. `crosswalk.py`: checks that every named test exists in the tree, marks a claim with no test as not evidenced, and writes `research/results/crosswalk.json` and the table.
3. `docs/compliance/README.md`: what the crosswalk is and is not. Engram supplies evidence; it does not make a deployment compliant, and the document says so in its first paragraph.
4. A MANIFEST row, so `make test-repro` reruns it.
