# E1.5 A Quint model of the commit and erasure protocol

Status: done on branch e1-5-quint-model, awaiting review. Paths: specs/commit.qnt, specs/README.md, Makefile (verify-spec), AGENTS.md, CLAUDE.md, docs/deps.md, docs/tasks/backlog.md, docs/log/2026-11-21-e1-5-*.md.

Goal: A checked model of the protocol card E2.6 built: several handles over one log, each deciding at the head and appending conditionally, with offboarding, adoption and a write after an erasure, and four safety properties the checker verifies within stated bounds.

Why: Tests sample interleavings and a model checker enumerates them. A checked model of "no writer on another handle undoes an erasure" is the strongest evidence the thesis can give for its hardest guarantee.

Steps:

1. A spike first, on a Windows machine: install Quint, run its simulator and the Apalache checker (which needs a JVM) on a toy spec, and log the outcome. If Apalache cannot run here, the card continues with the simulator alone and says so.
2. `specs/commit.qnt`: N handles, one log; the transitions decide at head, conditional append, offboard begin, sweep and report, adopt, write after erase, and the tombstone that stops a deleted item coming back.
3. Four safety properties: no event is appended against a stale head; an erased item's content appears in no later state; an offboarded scope accepts no later write; adoption never raises trust.
4. A deliberately broken variant (the conditional append removed) that the checker must refute, so a passing run means something.
5. `make verify-spec`, outside `make test`. `specs/README.md` states the bounds: this is bounded checking of a model, not a proof of the code.

Absorbs (mode per ADR 0037):

- Quint (Apache-2.0, depend): the specification language, a development tool only.
- Apalache (Apache-2.0, depend): the bounded model checker, a development tool only.
