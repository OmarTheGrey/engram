Status: planned, absorb plan 2.

Goal: On card E2.12's Cedar export, prove for all requests: strict never allows a read medium denies, nor medium one permissive denies; a model-sourced write never reaches a person scope it may not; another person never reads a person's item without a grant. 4. `make verify-policy`, outside `make test`, skipping with a message when cargo or cvc5 is missing.
