# E0.3 Interfaces: Plane, Adapter, ModelCall, Linter, Simulator, Distiller in TypeScript, with fakes

Status: partly done in step 0: the Adapter contract and its fake (S0.11), the Plane interface with a stub (S0.9) and ModelCall (S0.10). Linter, Simulator and Distiller interfaces are open.

Rewritten for ADR 0001: interfaces are TypeScript in `packages/core` and `packages/adapters`, not Python protocols.

Goal: declare the remaining interfaces from `docs/architecture.md` (Linter, Simulator, Distiller, and the Plane methods promote, lint, simulate, distill, explain) with typed stubs, and a fake for each that tests above layer 1 can use.

Files: `packages/core/src/plane.ts`, `packages/core/src/lint.ts`, `packages/core/src/simulate.ts`, `packages/core/src/distill.ts`, `packages/core/test/fakes/`

Depends on: E0.2, S0.9, S0.10, S0.11

Acceptance: `make lint` passes; `pnpm --filter core test` instantiates every fake

Out of scope: any policy logic (cards E2.x).
