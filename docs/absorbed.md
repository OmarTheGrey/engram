# Absorbed work

The register of everything copied or ported into this repository from open-source projects (ADR 0037; the procedure is `docs/conventions/absorption.md`). One row per copy or port, added in the same pull request as the code. Dependencies are in `docs/deps.md`. Ideas are cited in their cards. `make lint-docs` checks every row (card E0.6): the form it reads is in the convention's "Recording it" section, a mode marked `(data)` for data among it.
